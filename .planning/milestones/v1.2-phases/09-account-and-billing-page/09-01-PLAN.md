# Plan 09-01: Database DDL & Delivery Address API

## Goal
Build the backend infrastructure for users to save and retrieve a primary delivery address, distinct from whatever Stripe Checkout collected during past transactions.

## Requirements
- PROF-04: A signed-in user can view and edit one saved delivery address on the account page, persisted in the database.
- PROF-05: The account-page address is stored independently of the address Stripe Checkout collects.

## Files to Edit

### 1. `lib/db.js`
- **Schema Update:** Add the `addresses` table to `SCHEMA_SQL`:
  ```sql
  create table if not exists addresses (
    user_id bigint primary key references users(id),
    line1 text,
    city text,
    state text,
    postal_code text,
    country text
  )
  ```
- **Helpers:** Export two functions:
  - `getAddress(userId)`: `select * from addresses where user_id = $userId`.
  - `upsertAddress(userId, addressData)`: Use `insert ... on conflict (user_id) do update set line1 = excluded.line1, ... returning *`.

### 2. `api/address.js` (NEW)
- Implement `GET(request)`: 
  - Authenticate using `readSession`.
  - Fetch address from `getAddress(session.uid)`.
  - Return address JSON.
- Implement `POST(request)`:
  - Authenticate using `readSession`.
  - Parse address JSON from request body.
  - Call `upsertAddress(session.uid, addressData)`.
  - Return `{ success: true }`.
