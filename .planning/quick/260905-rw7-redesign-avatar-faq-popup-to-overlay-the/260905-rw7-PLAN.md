<objective>
Redesign the avatar FAQ widget's chrome so the question buttons float ON the video as
lettered pill rows on a dark scrim, and replace the "all 15 questions, always" list with
progressive disclosure: a small starter set, then keyword chips, then per-category questions.

Purpose: The current widget dumps 15 questions and 4 headings in a scrolling block below a
240px-tall video — visually generic and cognitively heavy. This lands the overlay chrome and
category-first navigation early (partially advancing FAQ-03 and WIDGET-03, which Phase 11
still owns end-to-end) without touching the Phase 10 video engine.

Output: An overlay-styled widget showing 3-4 starter questions with a "More topics" path to
all 15, built entirely inside the existing avatarFaq.jsx / avatarFaqData.js / styles.css files.
</objective>
