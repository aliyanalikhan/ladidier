# Quick Task 260831-o04: Restore Home Hero Cover Tilt Animation Summary

**Root cause:** quick task 260831-ndu (commit 5a714c1) swapped `HeroSplit`'s `<MagazineCover tilt />`
mockup for the real ÉCLAT Vol. 2 cover photo, but the replacement `<div className="ph photo">`
didn't carry over the `cover`, `framed`, and `tilt` CSS classes the mockup had — so the resting 3D
tilt, hover straighten-and-lift, and gold luxe frame silently disappeared. The outer wrapper's
`float-slow` bobbing animation was untouched and kept working, which is why only the tilt/frame
was noticed as missing.

**Fix:** added `cover framed tilt` to the existing `className="ph photo"` on that one div. These
CSS classes already existed (written originally for `MagazineCover`, styles.css lines 373-390 and
816-828) and apply cleanly to any `.ph.photo` element with no other changes needed.
