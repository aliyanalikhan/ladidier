# Quick Task 260905-t26: Move Avatar FAQ Widget Inline + Scroll-Gate Playback Summary

**Relocated the avatar FAQ widget from a fixed bottom-right popup (with a `createPortal` escape hatch) into an in-flow block inside Home's Manifesto left column, and replaced play-on-mount with an IntersectionObserver mount gate that starts the intro only on first scroll-into-view.**

## Performance

- **Duration:** ~5 min between commits (see note above — total session time including reads/verification was longer)
- **Tasks:** 3 of 4 (Task 4 is a blocking human-verify checkpoint, intentionally not attempted)
- **Files modified:** 5 (`src/pages.jsx`, `src/avatarFaq.jsx`, `src/styles.css`, `src/print-app.jsx`, `.planning/REQUIREMENTS.md`)

## Accomplishments

- **Task 1 — Relocate + de-portal + restyle:** `Manifesto` now accepts `printMode` and renders `<AIAvatarFAQ />` inside its `.col.gap-24` left column, directly under the Laurel graphic; `HomePage` passes `printMode` down and no longer mounts the widget itself. `createPortal`/`react-dom` removed entirely from `avatarFaq.jsx` (identifier and module specifier both gone, including comments). `.avatar-faq-widget` flipped from `position: fixed; right/bottom: 24px; z-index: 40` to `position: relative; width: min(100%, 320px); aspect-ratio: 9/16`, and the redundant `@media (max-width: 480px)` override (the file's final block) was deleted since the column already collapses to full width below 480px. `print-app.jsx`'s comment dropped the stale "fixed-position" descriptor.
- **Task 2 — Scroll-gated first playback:** `AIAvatarFAQ` split into a private `AvatarWidgetContent` (the unchanged video engine + overlay chrome) and a thin outer `AIAvatarFAQ` that always renders the sized `.avatar-faq-widget` box (reserving its layout slot immediately) but only mounts `AvatarWidgetContent` — and therefore only calls `useVideoAvatar()` — after a `{ threshold: 0.3 }` `IntersectionObserver` sees the box cross into view for the first time. The observer disconnects permanently after that one fire; scrolling the section out and back does nothing (by design). Falls back to immediate play-on-mount if `IntersectionObserver` is unavailable. Export surface (`export { AIAvatarFAQ };`), `avatarReducer.js`, `avatarFaqData.js`, and the mobile-nav-pause listener all untouched.
- **Task 3 — Requirements sync:** Amended `WIDGET-01`, `AVATAR-01`, and `WIDGET-04` in `.planning/REQUIREMENTS.md` to describe the inline, scroll-gated widget instead of the floating popup, each with an `(amended 2026-09-05, quick task 260905-t26)` marker. Checkbox states, requirement count, and the Phase-mapping table are byte-identical to before (diff is exactly 3 lines).
