# Quick Task 261126-u2x: Fix Falling Leaves Pink Color on Thanksgiving Theme

## Objective
The falling leaves currently use system emojis (`🍂`, `🍁`), which on Windows (Segoe UI Emoji) render the maple leaf `🍁` in a vibrant hot pink/magenta hue. Because half the leaves are `🍁`, users see a shower of bright pink leaves instead of warm autumn foliage.

Replace the system emoji leaves with elegant, bespoke SVG autumn leaves (maple, oak, and birch/aspen silhouettes) styled with explicit, warm autumnal harvest tones (`#C85A17`, `#D48B28`, `#9E381C`, `#B5501B`, `#E09C32`, `#A2481A`, `#8B2E1E`). This eliminates all vendor emoji color quirks across all operating systems and matches LaDidiér's luxury aesthetic.

## Tasks
1. Define SVG autumn leaf components (Maple, Oak, Aspen) with authentic Thanksgiving harvest tones in `src/pages.jsx`.
2. Update `.thanks-leaves` styling in `src/styles.css` to properly size and position the SVG leaves with subtle drop-shadow and smooth rotation.
3. Verify build with `npm run build` and visual preview.
4. Commit code changes atomically and update project state.
