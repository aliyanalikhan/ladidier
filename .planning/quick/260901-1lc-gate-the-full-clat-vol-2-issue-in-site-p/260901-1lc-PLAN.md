<objective>
Fix the gap surfaced in conversation: subscribing to ÉcLAT Online (or Hard Copy) charged a real
recurring Stripe subscription but delivered no visible or functional benefit — MagazinePage
stopped taking an `isMember` prop entirely once the interactive flipbook was retired, so a paying
member and an anonymous visitor saw byte-identical pages.

Locked decisions (confirmed with the user via AskUserQuestion before building):
- Members get BOTH an in-site page-by-page reader AND a PDF download — not just one.
- The 188MB source PDF is re-rendered at web-appropriate quality (compressed to ~15MB) rather
  than requiring the user to supply a separate file.
- The free "Reader" plan's pricing-card copy is left untouched — it keeps today's cover +
  6-highlight teaser view; only the full issue is gated.

Output: two new member-gated API routes serving a compressed PDF and per-page JPEGs from a
non-public `content/` directory (so the gate is a real server check, not client-side hiding), a
shared entitlement-check helper reused from the existing Stripe-backed membership system (no new
database, no new auth system — same mechanism `api/entitlement.js` already uses), and a
`MagazinePage` UI that branches on `isMember` to show either the existing free-visitor teaser or
a "Read the full issue" / "Download PDF" pair for members.
</objective>

  Node File Trace does not reliably bundle files reached only through a runtime-computed path
  (the page filename depends on a query param), so this is required for the routes to find their
  files in production, not just locally.
