| overlay links → setRoute | Link clicks pass hardcoded slug strings — no user-supplied data enters route system |
| Escape keydown → onClose | Keyboard event handler reads only e.key — no data from event payload used |

| T-01-jsx-02 | Denial of Service | keydown event listener | mitigate | Escape handler removed in useEffect cleanup on unmount; no persistent listener leak |
| T-01-jsx-03 | Denial of Service | focus trap listener | mitigate | Tab trap keydown listener removed in useEffect cleanup on unmount |
