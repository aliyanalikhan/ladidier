## Interaction Contract

### Hamburger Button

- **Visible at:** `≤768px` — desktop nav links hidden at same breakpoint
- **Position:** Far right of `.nav-right`, replacing the hidden links
- **Size:** 44px × 44px tap target; icon area 20px × 14px (3 bars, 2px thick, 6px gap)
- **Idle state:** 3 horizontal bars, color `var(--fg)`, opacity .82
- **Hover state:** opacity 1, `--gold` underline sweep (matches `.nav a::before` treatment)
- **Focus-visible state:** 1px `--gold` outline, 2px offset
- **Aria:** `aria-label="Open navigation"`, `aria-expanded={false|true}`, `aria-controls="mobile-nav-overlay"`

### Overlay Open

- **Trigger:** Tap hamburger button
- **Entry animation:** Full-screen overlay fades in + translates up 8px over 400ms `cubic-bezier(.2,.7,.2,1)` — matches existing `.page-fade` keyframe language (`opacity 0 → 1`, `translateY(8px) → none`)
- **Duration:** 400ms (slightly slower than the 500ms page fade — overlay is a heavier element)
- **Stagger:** Nav links stagger in 60ms apart after overlay reaches full opacity, using `.stg-i` pattern already in styles.css
- **Reduced motion:** All animations set to `animation: none` and transitions to `none` — inherits existing `@media (prefers-reduced-motion: reduce)` rule

### Overlay Layout

```
┌─────────────────────────────────────┐
│ [×] close          LaDidiér wordmark│  ← 64px from top, 24px horizontal pad
├─────────────────────────────────────┤
│                                     │
│  Magazine                           │  ← 28px display, 32px above first link
│  Stores                             │
│  Universe                           │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   │  ← --line divider
│  Search                             │
│  Subscribe                          │
│                                     │
│                                     │
│                                     │
├─────────────────────────────────────┤
│  EN · USD                           │  ← 48px from bottom, 11px mono
└─────────────────────────────────────┘
```

- **Position:** `position: fixed; inset: 0; z-index: 100` (above nav's z-index: 50)
- **Background:** `var(--bg)` at full opacity — not translucent (luxury editorial: solid page, not modal)
- **Grain texture:** Inherits `body::before` fixed grain overlay automatically (no extra work)

### Active Route Highlight

- **Visual:** Gold left border `3px solid var(--gold)` on the active link + text color `var(--fg)` at full opacity (not muted)
- **Inactive links:** Color `var(--fg)`, opacity .82 (matches existing `.nav a` idle state)
- **Hover on inactive:** opacity 1, `--gold` underline sweep (same `.nav a::before` pattern)
- **Implementation:** `className={route === slug ? "active" : ""}` — same pattern as existing desktop Nav

### Overlay Close

Two triggers — both must work:
1. **× button tap** — top-left or top-right of overlay (position: top-right, 24px inset)
2. **Escape key** — `keydown` listener added when overlay opens, removed when closed

Exit animation: reverse of entry — opacity 1 → 0 + `translateY(0 → 8px)` over 300ms. Unmount after animation completes (or immediately if reduced-motion).

**Aria on close:** `aria-label="Close navigation"`, same `aria-controls="mobile-nav-overlay"`

### Body Scroll Lock

While overlay is open: `document.body.style.overflow = "hidden"`. Restored on close.

### State Management

Single `useState` boolean `menuOpen` in the Nav component (or lifted to App shell if needed for route changes to auto-close the overlay). Overlay closes automatically on route selection.

## Animation Reference

Animations must feel editorial — never bouncy, never utilitarian.

| Animation | Duration | Easing | Property |
|-----------|----------|--------|----------|
| Overlay enter | 400ms | `cubic-bezier(.2,.7,.2,1)` | opacity 0→1, translateY 8px→0 |
| Overlay exit | 300ms | `cubic-bezier(.2,.7,.2,1)` | opacity 1→0, translateY 0→8px |
| Link stagger | 60ms per link, starts 200ms after overlay enter | `cubic-bezier(.2,.7,.2,1)` | same stgIn pattern: translateY(105%) skewY(6deg) → none |
| Hamburger hover | 300ms | ease | opacity .82→1 |
| Close button hover | 200ms | ease | opacity .82→1, color→var(--gold) |
| Reduced motion | all → 0ms / none | — | inherits existing prefers-reduced-motion block |

Source: styles.css `@keyframes pageFade`, `@keyframes stgIn`, `.nav a` transition values.
