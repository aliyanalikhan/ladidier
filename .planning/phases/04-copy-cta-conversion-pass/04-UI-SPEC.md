# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase type: copy-only.** This phase makes zero new components, zero new CSS classes, and zero new design tokens (per 04-CONTEXT.md domain boundary and 04-RESEARCH.md Architecture Patterns). Every visual/interaction value below documents the **existing, locked** design system that this phase must reuse exactly as-is — the contract's job here is to constrain copy/CTA edits to stay inside it, not to introduce anything new.

## Spacing Scale

Declared values already established in `styles.css` (this phase adds no new spacing — table documents the existing convention that any touched JSX must stay inside):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon/inline gaps |
| sm | 8-10px | Compact element spacing (e.g. `.foot ul` gap: 10px) |
| md | 14-18px | Default element spacing (card internals — e.g. `StoresPage` grid CTA row `paddingTop: 14`, `marginTop: 18`) |
| lg | 24-28px | Section/paragraph spacing (e.g. `SubscribeBanner` button row `marginTop: 28`) |
| xl | 32-36px | Layout gaps |
| 2xl | `clamp(56px, 7vw, 104px)` (`--section-y`) | Major section breaks, fluid by viewport |
| 3xl | `clamp(24px, 4vw, 56px)` (`--gutter`) | Page-level horizontal gutter, fluid by viewport |

Exceptions: this codebase's spacing is not a strict 8pt grid (14px/18px values exist pre-existing, e.g. `pages.jsx:740` grid-CTA row). This is a pre-existing convention, not introduced by this phase — **do not "fix" spacing to a stricter scale as a side effect of a copy edit.** Any new inline style this phase's edits require (e.g. wrapping a computed `{STORES.length}` span) must match the exact spacing already present on the line being edited, not a new value.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (browser default via `body`, no override) / `.lede` `clamp(18px, 1.5vw, 22px)`, collapses to 16px at ≤480px (per commit `b00cb97`) | 400 (`body { font-weight: 400 }`) | 1.45 (`--line-h`, body) / 1.5 (`.lede`) |
| Label / Eyebrow | 11px (`.eyebrow`, `.smcap`, `.mono` labels) | 400 (`.eyebrow`) / 500 (`.smcap`) | inherits body |
| Heading | `.h1` `clamp(48px,9vw,140px)` / `.h2` `clamp(36px,6vw,92px)` / `.h3` `clamp(24px,3.2vw,44px)` | 300 (`.display`, sans mode) / 400 (`[data-typeset="editorial"]`, serif mode) | 0.92 (`.display`) |
| Display | same as Heading (`.display` class drives both) | 300 / 400 (editorial toggle) | 0.92 |

No new type roles, sizes, or weights are introduced by this phase. All copy edits (hero headlines, ledes, CTA labels, store card microcopy) must render inside these four existing roles — a new size/weight for "emphasis" is an anti-pattern per `04-RESEARCH.md` Pitfall 2 analog (never invent new visual treatment for a copy-only change).

## Copywriting Contract

This is the substantive contract for this phase — CTA-01 through CTA-07 are fundamentally a copywriting/microcopy task. Voice, exact required strings, and discretionary drafts below are inherited directly from `04-CONTEXT.md` (D-01 through D-10, locked) and `04-RESEARCH.md`'s Copy & CTA Voice Patterns table (drafts, Claude's discretion per CONTEXT.md).

**Voice rule (locked, D-01):** Elevated editorial phrasing only — possessive/immersive verb ("Shop," "Enter," "Discover," "Visit") + house-branded noun ("the Houses," "the Boutique," "the Directory"). Never literal ecommerce phrasing ("Shop Now," "Browse Categories"), never exclamation points, never ALL CAPS beyond the site's existing `.mono`/`.eyebrow` typographic uppercase-tracking convention (a style, not an urgency device).

| Element | Copy |
|---------|------|
| Primary CTA — Home hero (all 3 variants: `HeroManifest`, `HeroSplit`, `HeroIndex`) | New shopping-forward CTA promoted to first position + `.btn.solid` (D-02, D-03, CTA-01). Draft: **"Shop the Houses"** or reuse existing on-voice string **"Enter the stores"** (`HeroManifest`) — executor's discretion on exact wording per hero, must be first/solid in all three. Existing "Read the issue"/"Open the issue"/"The full directory →" CTA is kept, demoted to second position, non-solid (`.btn` or `.btn.ghost`) — never removed. |
| Store card CTA — Stores page **grid view** (locked, D-05, CTA-03) | **"Visit the Boutique →"** exactly — replaces current "Enter →" at `pages.jsx:742`. Not discretionary. |
| Store card CTA — Stores page **list view** (locked, D-04) | No visible text change (stays bare "→"). Add `aria-label="Visit the Boutique — {store name}"` to the `.store-row` wrapper div, per-store (not a generic repeated label) so screen readers announce the store name. |
| Home `StoresPreview` eyebrow (locked bug fix, D-08, CTA-05) | Fix stale count: `"The Directory · {STORES.length} Houses"` (computed, preferred — matches existing precedent at `pages.jsx:158`) — never a second hardcoded number. |
| Home `StoresPreview` CTA | Draft: **"Discover the Directory →"** (explicitly pre-approved D-01 example phrase) — replaces "Open the directory →". |
| Home `StoresPreview` heritage microcopy (locked, D-06, CTA-05) | Add Est. year + category to each home preview card (currently name + category only) — read directly from existing `STORES[].est` / `STORES[].cat` fields, no new data. |
| Stores page intro/header lede (CTA-04) | Reframe toward inviting action while preserving existing editorial cadence (long sentence, semicolon/em-dash rhythm). Full-sentence discretion; must not read as a fresh rewrite, must not introduce ecommerce-register nouns. |
| Magazine header lede (D-07, CTA-06) | Light-touch shopping tie-in only — reference the houses that inspired the stories. Must not disturb the existing paywall/subscribe mechanic copy's transactional clarity. |
| Magazine paywall gate heading ("Subscribe to See All Pages") | **Do not reword.** Locked as-is — CTA-06 explicitly requires the shopping reframe to not disrupt paywall mechanics, and mechanic-clarity is part of that; shopping tie-in belongs in the surrounding lede, not the paywall CTA button. |
| `SubscribeBanner` dead CTA fix (locked, D-09, CTA-07) | "Continue reading freely →" gets a real `onClick` (e.g. smooth-scroll dismiss, matching existing `window.scrollTo({top:0, behavior:"smooth"})` pattern at `components.jsx:104`). Copy itself may stay as-is (already on-voice) — this is a functional fix, not a rewording requirement. Applies identically across all 5 render sites (Home, Stores, Magazine, Article, About) since `SubscribeBanner` takes no page-identity prop — do not special-case per page. |
| `MagazinePage` "Download issue (PDF)" dead CTA fix (newly found during phase research, in-scope per CTA-07) | No PDF asset exists. Do not fake a download. Repurpose the button into a working CTA — e.g. relabel to **"View full issue →"** and wire it to the same interaction as the existing "Open the issue"/flipbook entry point (scroll-to/focus the iframe or reuse the existing route-to-magazine-viewer action). Must not be left as an inert button. |
| Empty state | Not applicable — this phase touches no empty-data states (Home/Stores/Magazine always render static `STORES[]`/`ISSUE` data, never an empty collection). |
| Error state | Not applicable — this phase adds no new form/validation surface; the existing paywall email input (`pages.jsx:485`) and its error handling are unmodified. |
| Destructive confirmation | Not applicable — this phase introduces no destructive actions (no delete/remove/irreversible operations anywhere in Home/Stores/Magazine scope). |

**Calibration check (CTA-02/CTA-04, cross-cutting):** Before finalizing any new/reworded string, read it aloud immediately after the sentence it replaces — it must not produce a tonal jump (per `04-RESEARCH.md` Pitfall 1 mitigation, inherited from `.planning/research/PITFALLS.md`). Reject any draft containing `!`, "SALE," "NOW," a percentage/price outside the existing Subscribe plan cards, or countdown language.
