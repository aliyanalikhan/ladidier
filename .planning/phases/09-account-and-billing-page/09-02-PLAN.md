# Plan 09-02: Stripe Billing Portal Integration

## Goal
Implement a serverless endpoint that generates a secure, one-time link to Stripe's hosted Customer Portal, completely offloading billing management (invoices, card updates, cancellation) from our app to Stripe.

## Requirements
- PROF-03: The account page has a "Manage billing" action that opens Stripe's hosted Customer Portal.

## Files to Edit

### 1. `api/account/portal.js` (NEW)
- Implement `GET(request)` (or `POST(request)`):
  - Import `readSession` from `../../lib/session.js`.
  - Import `getStripe` from `../../lib/stripe.js`.
  - Import `getUserById` from `../../lib/db.js`.
  - Parse session. If not signed in, return 401.
  - Query Postgres for `users.stripe_customer_id` using `getUserById(session.uid)`.
  - If null (user has no billing history), return a 400 error indicating no billing portal is available.
  - Establish `return_url`: using `request.headers.get('origin') + '/#account'`.
  - Await `stripe.billingPortal.sessions.create({ customer: stripe_customer_id, return_url })`.
  - Return `{ url: session.url }` as JSON.
