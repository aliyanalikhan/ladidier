# Plan 09-03: Client UI & Navigation

## Goal
Build the user-facing `AccountPage` dashboard, update navigation so authenticated users land here instead of the Subscribe page, and implement the frontend for billing redirection and address management.

## Requirements
- PROF-01: Show name and avatar returned by Google.
- PROF-02: Show current membership/subscription status (via `isMember`).
- PROF-03: Provide "Manage billing" action linking to the Stripe Customer Portal.
- PROF-04: View and edit saved delivery address form.

## Files to Edit

### 1. `src/pages.jsx`
- **`AccountPage` Component (NEW):**
  - **Props:** `setRoute`, `user`, `isMember`.
  - **Profile Section:** Display `<img src={user.picture} className="account-avatar" />`, `user.name`, `user.email`.
  - **Status Section:** Display "Membership: Active (Digital & Print)" or "Membership: Inactive". (Or similar elegant copy based on `isMember`).
  - **Manage Billing Button:** Click handler that calls `GET /api/account/portal`, extracts `{ url }`, and sets `window.location.href = url`.
  - **Delivery Address Form:** Form fetching `GET /api/address` on mount and `POST /api/address` on submit. Include inputs for Address Line 1, City, State, Postal Code, Country.
  - **Sign Out Button:** Re-implement sign-out here (calls `/api/auth/logout` and resets auth states).
- **`SubscribePage` Cleanup:**
  - Remove the "Signed in as X / Sign out" row if desired, as it's now officially served by the Account page.

### 2. `src/app.jsx`
- Add `<AccountPage setRoute={go} user={user} isMember={isMember} />` to the switch statement under `case "account":`.

### 3. `src/components.jsx`

- Change its `href` to `#account` and its `onClick` handler to `setRoute("account")` instead of `subscribe`.
